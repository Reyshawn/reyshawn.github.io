随着年岁的增长，人是不是都会变得特别健忘，忘记昨天的午餐，上个月的某次聚会，半年前的某个功能更新和 bug 修复。这个时候我总会打开手机里的相册，查看 `git log`，日历，Notes，去看一看有没有在那天留下什么线索。这一幕像极了『Memento 记忆碎片』中的场景。当体内的激素经历几十年漫长的时间达到一个极其稳定的水平的时候，你发现极少会被一些事情引起情绪上的波动。一年里不同的节日庆祝，以及年末的此刻都是如此。

究竟是从哪一年开始，年末由兴奋欣喜，到怀旧感伤，以及目前的稀松平常呢？

> 年年岁岁花相似，岁岁年年人不同。

去年的这会儿自己也在写年终总结，写完后时间已经凌晨一点半了，突发奇想，想要下楼去看星星。于是冬天，凌晨一点半，穿好衣服，按下电梯，到楼下抬头仰望，火星正好位于头顶上方，通红明亮。那天是晴朗的深夜，肉眼能看到比以往更多的星星。

翻看相册，想到最近几年，每年固定的日程是不多的，一个是农历除夕会和爸爸妈妈一起拍一张全家福，说是一张但其实会拍到好多张。我也会给爸爸妈妈单独拍。另外就是此刻了。除此之外便无其他。

## 书

- 『萬曆十五年』

我极少看历史相关的书籍。但这本书文笔非常出色，很容易让人沉浸其中读下去。

其他技术类书籍今年倒没怎么看。因为大多数时间都在和 Codex / ChatGPT 聊天结对编程，AI 能够帮助我很快补足缺失的知识，这样我不必再像原来那要碰到不太懂的领域找好多书来看。

但后知后觉还是要继续找时间继续读书来着。

## 漫画

目前在追的漫画：

- 『天国大魔境』
- 『电锯人 第二季』
- 『名侦探柯南』

<img src="tengoku_daimakyo.jpg" width="300px" style="display: block;margin: 0 auto;">

『天国大魔境』是每月一更，已经接近尾声，是目前看到质量最高的漫画。我还没有看过石黑正数的其他作品，但石黑正数在『天国大魔境』中展现出来的多线叙事，细节和伏笔回收能力太强了。可能等漫画真正完结的时候，要重新再看一遍，追连载的过程总是忘记很多剧情。

<img src="sayonara_eri.jpg" width="300px" style="display: block;margin: 0 auto;">


藤本树也是我目前很喜欢的日本漫画家，看过他的『蓦然回首』『再见绘梨』『炎拳』都是特别出色的作品。当然『电锯人 第一季』也很棒。但不知道是不是因为周更的缘故。『电锯人 第二季』目前为止很乱，不管是画风还是剧情。

有生之年的愿望之一是希望看到『名侦探柯南』的结局。

## 时刻

### 再次前往香港

四月份和朋友又去了一趟香港。返程的时候朋友有事需要多留一天，我自己一个人深夜坐飞机返程，在飞机上看星星，突然就看到一颗流星。上次看到流星可能还是十多年前吧，此后不停的忙学业，工作，来回辗转，不曾再像少年时经常抬头看满月和星空。

> *2025.04.15 23:00*
>
> 晚上坐在深圳回上海的飞机，飞机飞过云层后，我一直盯着远处的夜空，第一次在飞机上看星星，星星更亮了。火星，北河二，北河三。然后忽然看到不远处有一颗流星划过。
>
> 不记得上次看到流星是多少年前了，这一次看到流星，也忘记了许愿。😖

### 组装高性能 PC

也就是六月份的时候，自己组装了一台高性能 PC，也是时隔七八年再一次使用 Windows 操作系统。想要组装一台高性能 PC 是去年（二〇二四年）就有的想法，后面因为 40 系显卡接近尾声，50 系显卡要发售就推迟到了今年。

上一次组装电脑还是很小时候爸妈带我去电脑城，写配置单，各个店铺买配件然后工作人员帮忙组装的。硬盘只有 80 GB，有软驱，有光驱，奔腾 D 处理器，使用风冷散热，显卡是一个叫「太阳花」的牌子。

我从周五晚上 20:00 开始着手组装，边看视频边看各种说明书，用着一把小螺丝刀，一直折腾到了凌晨三点，理线实在是太困难了，就先睡了。凌晨三点睡，七点就醒了。一大早起来开始折腾电源理线，一点一点，直到下午两点才总算大功告成。很累，前后总计花了十二小时的时间，要不停弯腰拧螺丝，小心翼翼接各种线材。起身的时候腿和腰都是酸的。完成之后去冲了一个热水澡，把出了汗的衣服放到洗衣机里洗一洗。散落一地的包装盒都整理干净。

那个时候心里畅快极了，那种畅快的感觉好多年都没有过。像是刚跑完一场五千米的长跑，洗完澡后躺在床上歇息的那种感觉。

### 折腾 Windows

我已经有七八年不曾使用过 Windows 操作系统。早已习惯了 macOS 一整套的快捷键和操作逻辑。所以组装完成 PC 后又花了好长时间把 macOS 的快捷键和操作逻辑搬到 Windows 上，以此保证我能够在两个系统的使用过程中无缝切换。快捷键配置部分我主要使用 AutoHotkey，一款极其强大的热键软件，又很轻量。没有用 PowerToys 是因为那个软件很重，占用不少内存且大部分功能我并不需要，快捷键映射部分也没有 AutoHotkey 强大。我把我目前使用的脚本文件放在了 github 上：

[Reyshaw/autohotkey](https://github.com/Reyshawn/autohotkey)

因为在 macOS 一直是使用触控板，在 Window 系统下不免要用到鼠标。其实我尝试把我的 Magic Trackpad 连接到 Window 上使用，也能用，支持一些简单的手势，四指左右滑切换桌面，四指上下滑显示和隐藏桌面等等。但终归比不上 macOS 上的使用体验。

我后面又购入一款罗技 G502x 鼠标，这款鼠标支持的自定义键很多。罗技的 ghub 软件支持用户编写 lua 脚本进行自定义内容，我就给鼠标的某些键加了一些手势进去，最终实现的效果就是想要在 Windows 上使用鼠标，就像 macOS 上的触控板一样方便和舒服。

我是在此脚本做了一些简单的修改，后续应该也会放在 github 上。

[mark-vandenberg/g-hub-mouse-gestures](https://github.com/mark-vandenberg/g-hub-mouse-gestures)

这部分的内容细节足够庞杂乃至可以单独写一篇文章出来。

### 键盘

此前我一直使用的是 MacBook 的蝴蝶键盘和剪刀脚键盘，配列手感都很舒服。

刚开始购买了一副 200 元左右的机械键盘，到手觉得前高太高了，整体太过笨重当即退掉了。后面买了 ROG 魔导士一代 NX，68 配列悬浮式结构，红轴，设计和做工都令人赏心悦目。缺点是没有轴体热插拔，以及部分键帽为了结构紧凑是非标准的。

我还挺喜欢悬浮式的机械键盘结构，但目前市场上只有大多数的游戏电竞键盘采用悬浮结构，且当前的游戏电竞键盘多用磁轴。还有就是始终都找不到一款 75 配列的悬浮式机械键盘。

### 血月

八月底的时候搬了一次家，新的房间有一个不大不小的飘窗，九月份血月那天，我躺在床上抬头就能看到月亮。那一次，我在房间里一边播放 Fly me to the moon，一边躺在床上就那样看完月全食的完整过程。在月球即将进入地球阴影的那个瞬间特别美，可惜相机没办法捕捉到。

### 猫

新的住处，每天傍晚时分都会有一只橘猫在楼下等待投喂。橘猫是一只流浪猫，左耳被剪去一角，已经被绝育了。我后来也买了些猫粮来投喂橘猫，不久便和我相当熟悉，每次远远看到我便竖起尾巴跑过来朝我喵喵叫。

## 结语

我很喜欢我现在的状态。不管是生活环境，软件，硬件都在一个极度熵低的状态。

Everything is in order. Everything is all set.

我还是想要自己能够不断的思考和解决问题来着。我会认为不停的思考，动手，寻找解决方案，并最终把问题解决掉的过程特别美妙。

人随着年岁的增长，会变得健忘，会变得更加情绪稳定，看待很多事情开始变得更加的稀松平常，小到日常，大到生死。但我想有一点是可以帮助打破这个规律，那就是**好奇心**。我庆幸我现在对很多事情还是保有好奇心的，无论是领域内各类开发相关技术，还是领域外的历史，物理，语言等等。多年前就曾在文章里写到过，也许最让人兴奋的，还是在有限的时间内目睹历史的发展和世界的变化吧。
